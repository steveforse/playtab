# alphaTab rendering patch

`@coderline+alphatab+1.8.4.patch` changes the ESM renderer consumed by this app so hammer-on and pull-off tablature slurs both arch upward, regardless of string. Adjacent H/PO segments are split into separate curves so a 0→2→0 passage receives both visible transitions. It also gives H/PO pairs a dedicated MIDI path: the origin sample is held on an isolated channel, receives an immediate per-note pitch step at the destination onset, and gets an audible short contact at the exact destination pitch from the selected SoundFont. This preserves the held legato voice without adding a second full picked attack or a slide glyph. Printed slide labels are centered above the beat's highest tab note while retaining upstream slide playback. T/I/M fingering annotations are rendered as centered, one-letter-per-line stacks, and imported section words or rehearsal markers are drawn in shared bands below the tablature staff because this preview hides alphaTab's standard notation staff. After-graces are supported: a MusicXML grace with `steal-time-previous` imports as a before-beat grace, and a before-beat grace group at the end of a bar (no following beat) takes its time from the preceding beat so it sounds before the barline, and is drawn in the space the bar reserves for it just before the barline instead of over the preceding beat. Both `alphaTab.core.mjs` and the worker bundle `alphaTab.js` carry the grace changes. The AudioWorklet path also guards a rapid play/pause race: an asynchronous worklet setup must not start a source after playback has stopped or call `stop()` on a source that has not started.

`npm ci` applies it through `patch-package`; failed application fails installation. The frontend Docker build copies patches before installing. Revalidate H/PO curves, label placement, after-grace timing and placement, resizing, and printing when upgrading alphaTab. The unconsumed CommonJS and pre-minified bundles are not patched.

The modified alphaTab code remains MPL-2.0. Preserve its original notices and this patch when distributing the application. Upstream source: https://github.com/CoderLine/alphaTab (version 1.8.4).
