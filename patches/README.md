# alphaTab rendering patch

`@coderline+alphatab+1.8.4.patch` changes the ESM renderer consumed by this app so hammer-on and pull-off tablature slurs both arch upward, regardless of string. Adjacent H/PO segments are split into separate curves so a 0→2→0 passage receives both visible transitions. It also gives H/PO pairs a dedicated MIDI path: the origin sample is held on an isolated channel, receives an immediate per-note pitch step at the destination onset, and gets a short, quiet attack transient from the selected SoundFont. This preserves the held legato voice without adding a second picked attack or a slide glyph. Ordinary slides retain the upstream placement and interpolated playback. Native left-hand thumb fingerings are drawn as uppercase `T` markers, and imported section words or rehearsal markers are drawn in shared bands below the tablature staff because this preview hides alphaTab's standard notation staff.

`npm ci` applies it through `patch-package`; failed application fails installation. The frontend Docker build copies patches before installing. Revalidate H/PO curves, label placement, resizing, and printing when upgrading alphaTab. The unconsumed CommonJS and pre-minified bundles are not patched.

The modified alphaTab code remains MPL-2.0. Preserve its original notices and this patch when distributing the application. Upstream source: https://github.com/CoderLine/alphaTab (version 1.8.4).
